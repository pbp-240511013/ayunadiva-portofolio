# Ayunadiva — Personal Portfolio

Website portofolio statis menggunakan HTML, CSS, dan JavaScript.

## Cara menjalankan
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.
3. Edit konten sesuai data diri yang benar.

## Sebelum dipublikasikan
- Ganti email dan tautan GitHub/LinkedIn di bagian `contact` pada `script.js`.
- Tambahkan tautan repository/demo pada kartu proyek jika sudah siap dibagikan.
- Tambahkan foto profil jika ingin (desain saat ini memakai monogram A).
- Tambahkan CV PDF dan tombol unduh jika file CV sudah tersedia.

## Deploy ke GitHub Pages
1. Buat repository GitHub baru, misalnya `portfolio`.
2. Upload `index.html`, `style.css`, dan `script.js` ke root repository.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
5. Tunggu proses deploy, lalu buka URL GitHub Pages yang ditampilkan.

Catatan: Deskripsi proyek saat ini merupakan ringkasan awal berdasarkan informasi yang tersedia. Pastikan detail dan status proyek sesuai kondisi sebenarnya sebelum dipakai melamar.
